# Ziad Swimming Performance Dashboard

A simple HTML-based dashboard for organizing Ziad’s swimming performance notes, race context, photos, videos, and embedded performance data.

## Purpose

This dashboard is intended to help review race performance in a structured way by combining:

- Race notes
- Start/block conditions
- Warm-up and caffeine information
- Suit and shaving context
- Dolphin-kick and race-execution notes
- Photos and video-review links
- Embedded Google Sheets performance data

## Main Focus

The current technical flag is:

**HAND SLIPPED ON BLOCKS**

This should be treated as an important contextual factor when interpreting the race time. A compromised start may mean that the final time does not fully represent Ziad’s true swimming capacity.
